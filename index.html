01 / About

Backend first, hardware always

By trade I work on backend software for industrial rolling-mill systems: C#, API design and database modeling. When the code drives heavy machinery, “it works on my machine” is not enough.

On my own time I follow the signal down to the hardware. I designed a triaxial seismograph around GD-4.5 geophones, wrote the acquisition daemon, the archive API and the live dashboard, and I keep recording local earthquakes with it. Around that: ESP32 and Arduino firmware, an antenna rotator for satellite passes, and tools for radiosonde hunters.

Due to my job, lately I am also learning PLC programming on Siemens TIA Portal V19 (the basics, in LAD and SCL). I also used to scan the sky for weather-satellite images: NOAA APT (RIP), Meteor LRPT on VHF, and on L-band Meteor HRPT, Metop AHRPT and Elektro-L LRIT.

Frontend is the part I am still learning to write “without emotional damage”, but Angular pages do ship, and they usually work.

rpi-seism: an open-source 3-axis seismograph

Docs ↗ Stack ↗ Org ↗

A proof-of-concept seismograph for local monitoring in an earthquake-prone area. Three GD-4.5 geophones feed an ADS1256 ADC read by an Arduino; data travels over RS-485 to a Raspberry Pi, and comes out as MiniSEED archives and a live dashboard. One docker compose up deploys the software side.

  1. 3 x GD-4.5geophones, 4.5 Hz
  2. ADCADS1256 24-bit
  3. RS-485differential link over Cat5/6
  4. Pi daemonPython · ObsPy · ZeroMQ
  5. OutputsMiniSEED/SDS · WebSocket · SeedLink · alerts

Firmware

Arduino-class C++ with a 16-byte checksummed packet format, runtime-configurable sampling rate, gain and data rate, built with PlatformIO across AVR, RP2040, STM32, ESP32 and Teensy.

Daemon

Threaded acquisition: reader, MiniSEED writer, WebSocket sender, STA/LTA trigger, Apprise notifications and a ringserver feed, with health tracking of link quality.

API & web

FastAPI archive with server-side FFT and spectrograms; Angular + PrimeNG + Tailwind dashboard with live traces, bookmarks and waveform export.

Recorded so far without external amplification: the Verzegnis swarm, events near Moggio Udinese and Lusevera, and two events in Slovenia/Croatia.

03 / Homelab

Self-hosting as a lifestyle (and a budget strategy)

Self-hosting has been my hobby for over ten years, and these days it’s partly powered by the sun. About 35 containers in 20 Docker Compose stacks run on a small ThinkCentre (Ubuntu LTS), managed with Ansible through Semaphore UI and housed in a 12U rack. Traefik routes the traffic and Authentik handles sign-in, with AdGuard Home for DNS filtering. The services themselves range from Paperless-ngx and Jellyfin to Syncthing and code-server, with Backrest taking the backups and Beszel and WatchYourLAN doing the monitoring.

To reach it from outside, I use WireGuard in a hub-and-spoke setup from a VPS, with Tailscale alongside. Inside the house, Home Assistant connects Zigbee2MQTT, ESPHome, a Modbus solar inverter and the 3D printer into one dashboard, and a small container even turns off the switch LEDs at night.
